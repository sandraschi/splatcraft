# `splatcraft-mcp` (L2 CLI & MCP Stdio Server)

Dual-mode `clap` CLI and Model Context Protocol (`stdio`) server exposing 13 tools (`splat_inspect`, `splat_convert`, `splat_edit`, `splat_merge`, `splat_render`, `splat_worlds`, `splat_train`, `splat_engine_status`, `splat_mesh`, `splat_recolor`, `splat_recipe`, `splat_trellis`, `splat_synth`).

```powershell
cargo run -p splatcraft-mcp -- engines
cargo run -p splatcraft-mcp -- mcp
```
