# `splat-ops` (L1 Pure Splat Edit Pipeline)

Pure, deterministic edit operations on Gaussian splats: box `crop` (with optional invert), `prune` (opacity/scale/non-finite), `transform` (translate, uniform scale, axis-angle rotation), `merge` (2–64 mixed PLY/SPZ files), and `reduce_sh` (explicitly blocking rotation on SH degree > 0).
